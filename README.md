# ShopSphere

A full-stack e-commerce platform built to demonstrate production-oriented .NET development, React, and Microsoft SQL Server.

## Technology Stack

- **Backend:** C# and ASP.NET Core Web API (.NET 10)
- **Frontend:** React, Vite, JavaScript
- **Database:** Microsoft SQL Server
- **ORM:** Entity Framework Core
- **Version Control:** Git and GitHub

## Architecture

ShopSphere will start as a modular monolith and progressively adopt Clean Architecture.

Planned backend layers:

- Domain
- Application
- Infrastructure
- API

## Planned Features

- Product catalog and search
- Customer accounts and authentication
- Shopping cart and checkout
- Orders, payments, and inventory
- Administration and reporting
- Automated tests and CI/CD
- Supplier product-feed processing using C# and XML/XSD
